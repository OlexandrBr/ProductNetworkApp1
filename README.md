Клієнт-серверний мережевий додаток для пошуку товарів у базі даних Excel.

Server (серверна частина):
- завантажує список товарів з Excel-файлу
- зберігає товари в пам’яті
- приймає запити від клієнтів
- виконує пошук товарів за найменуванням
- відправляє клієнту інформацію про товар:
  - найменування
  - ціну
  - кількість
  - загальну суму
 
Cient (клієнтська частина):
- підключається до сервера
- надсилає назви товарів
- отримує відповідь від сервера
- відображає результати пошуку
